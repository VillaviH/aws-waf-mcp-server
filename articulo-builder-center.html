El Problema: Logs de WAF que nadie lee

Si tienes AWS WAF protegiendo tus aplicaciones, sabes que genera miles de eventos por hora. Cada request bloqueado, cada regla disparada, cada IP sospechosa — todo queda registrado en S3. El problema es que nadie los lee.

La realidad en la mayoría de los equipos es esta: los logs de WAF se acumulan en S3, se paga por el almacenamiento, y solo se revisan cuando ya ocurrió un incidente. Para ese momento, el atacante ya se fue — o peor, ya entró.

⚠️
El problema real

En un análisis de un día típico (7 de mayo de 2026), encontramos 839 requests a archivos .env — de los cuales 775 fueron PERMITIDOS por el WAF. Eso significa que potencialmente 775 intentos de robo de credenciales pasaron sin ser bloqueados.

La solución tradicional requiere: descargar los logs, descomprimirlos, escribir queries en Athena o scripts en Python, interpretar los resultados, y repetir el proceso cada vez que quieres una respuesta diferente. Es tedioso, lento, y requiere conocimiento técnico especializado.

¿Y si pudieras simplemente preguntarle a tu asistente de IA: "¿Qué ataques detectaste hoy?" y obtener un análisis completo en segundos? Eso es exactamente lo que hace aws-waf-logs MCP Server.

🤖

¿Qué es el Model Context Protocol (MCP)?

El Model Context Protocol (MCP) es un estándar abierto creado por Anthropic que permite a los modelos de lenguaje (LLMs) conectarse con herramientas externas de forma estandarizada. Piénsalo como una "API universal" para que la IA pueda usar tus sistemas.

💡
Analogía simple

Si los LLMs son el cerebro, MCP es el sistema nervioso que les permite mover las manos (ejecutar herramientas), ver (leer archivos), y escuchar (consultar APIs).

Con MCP, puedes crear un servidor que expone funciones específicas de tu infraestructura, y cualquier cliente compatible (Claude Desktop, Amazon Q, Kiro IDE, etc.) puede invocar esas funciones de forma natural, dentro de una conversación.

El flujo es simple:

  1. El usuario hace una pregunta en lenguaje natural al asistente de IA
  2. El LLM identifica qué herramienta MCP necesita usar
  3. El servidor MCP ejecuta la función y devuelve los resultados
  4. El LLM interpreta los resultados y responde al usuario
🏗️

Arquitectura del Sistema

El servidor MCP actúa como intermediario entre el agente de IA y los logs de AWS WAF almacenados en S3. La arquitectura es deliberadamente simple: no requiere bases de datos, no necesita infraestructura adicional, y funciona con las credenciales AWS que ya tienes configuradas.

El servidor se ejecuta localmente en tu máquina. Cuando el agente de IA necesita analizar logs, invoca las herramientas del servidor MCP, que a su vez usa boto3 para descargar los archivos desde S3 y los procesa en memoria. Los resultados se devuelven como texto estructurado que el LLM puede interpretar.

✅
Sin infraestructura adicional

No necesitas Athena, no necesitas Elasticsearch, no necesitas ningún servicio adicional. Solo Python, tus credenciales AWS, y el servidor MCP corriendo localmente.

🛠️

Referencia de Herramientas

El servidor expone 11 herramientas organizadas en tres categorías: descarga de logs, análisis, e investigación forense.

Instalación y Configuración

La instalación toma menos de 5 minutos. Solo necesitas Python 3.10+, credenciales AWS configuradas, y el cliente MCP de tu preferencia.

1

Clonar el repositorio

Descarga el código del servidor MCP desde GitHub.

bash 
git clone https://github.com/tu-usuario/aws-waf-mcp-server.git
cd aws-waf-mcp-server
2

Crear entorno virtual e instalar dependencias

Se recomienda usar un entorno virtual para aislar las dependencias.

bash 
python3 -m venv venv
source venv/bin/activate  # En Windows: venv\Scripts\activate

pip install mcp boto3 python-dotenv
3

Configurar credenciales AWS

El servidor usa el perfil AWS configurado en tu sistema. Asegúrate de tener permisos de lectura en S3.

bash 
# Verificar que tienes acceso al bucket de logs
aws s3 ls s3://tu-bucket-waf-logs/ --profile default

# Política IAM mínima requerida:
# s3:GetObject, s3:ListBucket en el bucket de logs
4

Configurar el cliente MCP

Agrega el servidor a la configuración de tu cliente MCP. Aquí el ejemplo para Claude Desktop y Kiro IDE:

json — mcp.json 
{
  "aws-waf-logs": {
    "command": "/ruta/a/venv/bin/python3",
    "args": ["/ruta/a/aws-waf-mcp-server/server.py"],
    "env": {
      "AWS_PROFILE": "default",
      "AWS_REGION": "us-east-1"
    },
    "disabled": false,
    "autoApprove": [
      "analyze_waf_logs",
      "get_blocked_requests",
      "search_by_ip",
      "search_by_uri",
      "get_rule_details"
    ]
  }
}
💡
autoApprove

Las herramientas en autoApprove se ejecutan sin pedir confirmación al usuario. Se recomienda incluir solo las herramientas de lectura (no las de descarga masiva).

5

Verificar la instalación

Reinicia tu cliente MCP y verifica que el servidor aparezca disponible.

bash 
# Probar el servidor directamente
python3 server.py

# Deberías ver:
Starting aws-waf-logs MCP Server...
Registered 11 tools
Server ready on stdio

Detalles de Implementación

El servidor está construido con el SDK oficial de MCP para Python. Cada herramienta es una función decorada con @mcp.tool() que recibe parámetros tipados y devuelve texto estructurado.

python — server.py (fragmento) 
from mcp.server.fastmcp import FastMCP
import boto3, gzip, json

mcp = FastMCP("aws-waf-logs")

# Herramienta de análisis de día completo
@mcp.tool()
def analyze_full_day(directory: str) -> str:
    """Analiza TODOS los archivos de logs en un directorio.
    Genera reporte consolidado con totales, reglas, IPs,
    países, dominios y tráfico por hora."""

    total = blocked = allowed = 0
    rules = {}
    countries = {}
    hourly = {}

    for file in Path(directory).glob("**/*.gz"):
        with gzip.open(file) as f:
            for line in f:
                log = json.loads(line)
                total += 1
                action = log.get("action", "")

                if action == "BLOCK":
                    blocked += 1
                    # Extraer regla que bloqueó
                    for rule in log.get("terminatingRuleMatchDetails", []):
                        name = rule["terminatingRuleId"]
                        rules[name] = rules.get(name, 0) + 1
                else:
                    allowed += 1

    block_rate = (blocked / total * 100) if total > 0 else 0

    return format_report(total, allowed, blocked, block_rate, rules, countries)

FastMCP vs MCP SDK base

El servidor usa FastMCP, una capa de alto nivel sobre el SDK de MCP que simplifica enormemente la definición de herramientas. Con un simple decorador @mcp.tool(), FastMCP genera automáticamente el schema JSON, maneja la serialización y registra la herramienta en el servidor.

Conclusión

El servidor MCP aws-waf-logs transforma la forma en que interactuamos con los logs de seguridad. Lo que antes requería horas de trabajo manual — descargar logs, escribir scripts, interpretar resultados — ahora se hace en segundos con una pregunta en lenguaje natural.

El análisis del 7 de mayo de 2026 demostró el valor real: en minutos identificamos una brecha crítica (775 requests a archivos .env permitidos) que de otra forma habría pasado desapercibida en los miles de eventos del día.
